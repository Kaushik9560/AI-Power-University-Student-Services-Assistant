# Verbatim NSUT synthetic-name generation prompts

## System

Generate fictional Indian-style student names for a software test fixture. Do not use real student rosters or external personal data. Return ONLY a JSON object with a names array of exactly 32 distinct full names.

## User

Generate 32 distinct fictional full names, each at least 3 characters long. No IDs, numbers, prose or markdown. These will label entirely synthetic NSUT demo records.

Temperature: 0.4. Exact model, call count, outputs and validation are in generation_run.json. Numerical records and edge cases are assigned by code.
